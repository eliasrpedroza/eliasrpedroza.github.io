# eliasrpedroza.github.io

Source for my robotics portfolio → **https://eliasrpedroza.github.io**

Built with [Jekyll](https://jekyllrb.com/) and hosted on GitHub Pages. GitHub rebuilds the site automatically every time I push.

| What | Where |
|---|---|
| Projects (one file = one page) | `_projects/*.md` |
| Home page grid | `index.html` |
| About page | `about.html` + `_data/about.yml` |
| Resume | `assets/Elias_Pedroza_Resume.pdf` |
| Images and videos | `assets/img/…`, `assets/video/…` |
| Colors and layout | `assets/css/style.css` |
| Name, email, links | `_config.yml` |

- First-time setup: **PUBLISHING.md**
- Editing text, pictures, layout, and adding projects: **HOW-TO-EDIT.md**
- New project starter: `_templates/new-project.md`
